# 前期自主学习路线

这组教程服务于项目启动阶段。目标不是系统学完所有计算机与测绘知识，而是让三名成员能够共同完成：

> 读取项目数据 → 建立最近建筑基准 → 正确评价结果 → 使用 Git 协作和复现。

## 建议学习顺序

| 周次 | 主题 | 本周必须留下的成果 |
|---|---|---|
| 第 1 周 | Git | 每个人完成一次独立分支和 Pull Request |
| 第 2 周 | Python | 读取一个 CSV，检查字段并输出统计结果 |
| 第 3 周 | GIS/CRS | 将 GPS 和建筑转换到同一投影坐标系并画图 |
| 第 4 周 | CityGML | 提取 10 栋建筑的 ID、坐标系和几何范围 |
| 第 5 周 | 实验评价 | 实现 Top-1、Recall@5 和错配率计算 |
| 第 6 周 | 综合练习 | 跑通 30～50 张照片的最近建筑基准 |

实际可以交叉学习，但不要同时开始深度学习、三维重建和复杂服务器部署。

## 每份教程的使用方法

每次学习采用同一个循环：

1. **阅读**：先理解概念和示例，不背命令；
2. **动手**：在项目样例数据上运行教程中的练习；
3. **解释**：能向另一名组员说明输入、输出和风险；
4. **提交**：把代码、说明或结果通过 Git 提交；
5. **复盘**：记录一个遇到的问题和解决方法。

## 前期学习完成标准

当三名成员都能完成以下任务时，前期学习才算通过：

- [ ] 能创建分支、提交修改、推送并创建 Pull Request；
- [ ] 能创建 Python 虚拟环境并运行项目脚本；
- [ ] 能解释项目中每个数据字段的含义和单位；
- [ ] 能确认 CityGML 与 GPS 使用的坐标参考系；
- [ ] 能从 CityGML 中提取建筑 `building_id` 和几何；
- [ ] 能实现最近建筑基准；
- [ ] 能按建筑划分数据，并计算 Top-1 和 Recall@5；
- [ ] 能记录一次完整、可复现的实验。

## 学习记录建议

每位成员可以在自己的分支中维护一份简单记录：

```text
日期：
今天学习的主题：
运行的命令：
得到的结果：
遇到的问题：
下一步：
```

学习记录不追求长篇笔记。能留下可运行代码、真实输出和明确问题，比摘抄大量定义更有价值。
